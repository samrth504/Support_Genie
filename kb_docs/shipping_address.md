# Shipping Address Help

## Adding a new address
Go to **Profile → Saved Addresses → Add New Address**. Enter the full name, mobile number, pincode, house/flat number, street, landmark, city and state. You can save up to **10 addresses** and mark one as **Default**.

You can also add a secondary address (for example, office) and choose it at checkout.

## Changing the address of an existing order
The delivery address of an order can be changed **only before the order is Packed**: **My Orders → select order → Modify Order → Change Address**. The new address must be in a serviceable pincode, and the delivery date may change.

**After an order is Packed or Shipped, the address cannot be changed.** If you will not be available, you can cancel the order before it ships or refuse the delivery.

## Editing or deleting a saved address
Go to **Profile → Saved Addresses**, tap the address, then **Edit** or **Delete**. Changes to a saved address do not affect orders that have already been placed.

## Address tips for faster delivery
- Add a clear landmark.
- Use a mobile number that is reachable on the delivery day.
- For offices and gated societies, add the gate number or reception details.
