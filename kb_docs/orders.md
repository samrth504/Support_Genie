# Orders Help

## Placing an order
Add items to your cart, tap **Checkout**, choose a delivery address and a payment method, then tap **Place Order**. You will receive an order confirmation by SMS and email with your order ID. ShopNest order IDs look like **SN-12345678**.

A single order can contain up to 20 items. Items from different sellers may be delivered in separate packages, each with its own tracking.

## Tracking your order
Go to **Profile → My Orders** and select the order to see its live status. Order statuses are:
1. **Confirmed** – we have received your order.
2. **Packed** – the seller has packed your item.
3. **Shipped** – handed over to the courier; a tracking link is shared by SMS.
4. **Out for Delivery** – the delivery partner will reach you today.
5. **Delivered**.

If the status has not changed for more than 3 days after shipping, please contact support with your order ID.

## Changing an order
You can change the quantity, size, colour or delivery address of an order **only before it is Packed** (usually within 2 hours of placing it). Go to **My Orders → select order → Modify Order**.

Once an order is Packed or Shipped, it cannot be changed. You can cancel it if it has not shipped yet, or return it after delivery if the item is eligible for return.

## Order history
All orders from the last 2 years are visible in **My Orders**. Use the filter to search by date, status or product name.

## Missing or wrong items
If an item is missing from your package or you received the wrong item, report it within **48 hours of delivery** from **My Orders → select order → Report an Issue**, and attach a photo of the package and the item received.

## Order not placed but money deducted
If money was deducted but no order ID was generated, the payment is automatically reversed to the original payment method within 5–7 working days. See the Payments Help page for details.
